# Display app icon

Generated with the built-in ImageGen tool for YKONNECT Display. The source PNG retains transparency; the ICO is a format conversion containing 16, 24, 32, 48, 64, 128 and 256 pixel variants.

Prompt: A polished Windows desktop application icon for YKONNECT Display, a school display-screen player. Single centered icon on transparent canvas, rounded-square royal blue tile, white monitor outline, turquoise rising three-bar progress motif, short white monitor stand. Crisp geometry, subtle blue gradient, legible at 32px, no text or letters.

Used by Windows executable resources, NSIS installer/uninstaller, application windows and the notification-area tray.
