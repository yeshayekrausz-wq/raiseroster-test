Extract and upload the motivation folder to the repository root, preserving folders. No SQL or EXE update required. Refresh admin and restart the display player after deployment. Display Settings > choose computer > Slideshow / video > Media URL. Choose Picture or Video, Add URL, then Save display settings. Use a public direct HTTPS media file link, not a sharing/webpage link. Files stream from the external host; only URLs/settings are stored in Supabase. The upload size limit does not apply to URL files. Availability and playback depend on the host, internet connection and supported media format. Uploaded media remains supported.
