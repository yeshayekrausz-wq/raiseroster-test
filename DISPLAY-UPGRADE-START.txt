דיספלעי אפגרעיד — ווערסיע 1.1

1. עקסטרעקט דעם נייעם ZIP און אפלאוד דעם אינהאלט אין GitHub, מיט די זעלבע פאלדערס.

2. אין Supabase SQL Editor לויף נאר דעם נייעם Activate_Display_Upgrade.sql.
מען דארף נישט נאכאמאל לויפן דעם אלטן Activate_Display_Devices.sql.
נוץ Notepad צו קאפירן דעם גאנצן פייל. ביי דער ווארענונג: Run / Run without RLS.
דער אפגרעיד לייגט נישט צו קיין נייע טאבעלעס און טוישט נישט די עקזיסטירנדע RLS.
ס׳דארף ענדיגן מיט DISPLAY_UPGRADE_READY.

3. אפדעיט די Supabase Edge Function display-photo מיטן נייעם פייל:
supabase/functions/display-photo/index.ts
JWT verification בלייבט אויסגעלאשן. די פונקציע באשטעטיגט אליין דעם דיווייס.
דאס דארף מען פאר די נייע ווידיאס און סליידשאו־בילדער.

4. אינסטאליר דעם נייעם Windows EXE, אדער פובליש דעם נייעם GitHub Release
דורכן Actions → Windows display player → Run workflow.
נאר אפלאודן די וועבזייטל־פיילס טוישט נישט דעם אלטן Windows־פענסטער.
דער אינסטאלער איז געבויט, אבער דער Windows־אינסטאלירונג און אויטאמאטישער
אפדעיט דארפן נאך א פראבע אויף אן אמתן Windows־קאמפיוטער.

וואס איז ניי:
- אין אויסגעלאשענע שעות בלייבט א שווארצער פול־סקרין, אן דעסקטאפ אדער טעקסט.
- Select All / Clear All ביי די כתות.
- Bright / high contrast אדער Dark.
- Undo / Redo, Duplicate, Preview און גענויע פלאץ/גרייס־פעלדער פאר טעקסט־קעסטלעך.
- סליידשאו פון MP4, WebM אדער בילדער, מיט סדר און צייטן.
- מען קען שפילן נאר קינדער, נאר סליידשאו, אדער ביידע איינס נאכן צווייטן.
- סקענען א קינד שטעלט צייטווייליג אפ דעם סליידשאו.
- PowerPoint: עקספארט צו MP4 פאר אנימאציעס, אדער צו JPG/PNG סליידס.
  רויע PPTX־פיילס ווערן נישט אפגעשפילט דירעקט. ווידיאס שפילן אן קול.
- מאקסימום 25 MB פער פייל, לויט דער עקזיסטירנדיקער סטארעדזש־גרעניץ.

דער דיווייס־קאוד:
די 9 ציפערן בלייבן פעסט, אויך נאכן פארבינדן, ריסטארטן און אפדעיטן.
ביי אן אלטן שוין פארבונדענעם דיווייס וואס האט מער נישט געהאט א קאוד,
ווערט איין מאל באשאפן א נייער פעסטער קאוד.
אין דער Windows־עפפ: Display connection → Change code.
פארן טוישן קומט א באשטעטיגונג. די אלטע פארבינדונג און אירע סעטינגס ווערן
אפגעשטעלט; מען פארבינדט מחדש מיטן נייעם קאוד. קינדער און נקודות בלייבן.
דער אלטער קאוד קען מער נישט ווערן געניצט. דער עדמין דערקענט דעם טויש
ביים קומענדיגן אפפרישן; אלטע סעוו־בקשות ווערן גלייך אפגעווארפן.
